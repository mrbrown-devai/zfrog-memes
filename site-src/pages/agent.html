What the agent does

ZFROG Mark 1 is a small program that runs on a machine the team controls. Twice a day it wakes up, looks at its wallets, and follows five rules:

  1. Bridge. Any $ZAMA sitting on Solana goes to Ethereum through Zama's official LayerZero bridge, because that is where staking and the confidential vaults live.
  2. Stake half. About half of each batch is delegated to the Zama Protocol operator with the best net APR after commission. The agent scans every operator each run.
  3. Shield the rest. The other half is swapped to a stablecoin, shielded into its confidential version, and deposited into the Zama confidential vault with the best yield.
  4. Review on Mondays. Once a week it compares vault yields and operator rates and moves funds only if the gap is worth the fees.
  5. Report. Every action, with the transaction hash, is logged. The log feeds this page.

How it is kept safe

  • Keys never leave the machine. The wallets were generated locally and are stored encrypted. No AI model and no cloud service has ever seen them.
  • Allowlist only. The agent can only talk to Zama Protocol contracts, the official bridge and the swap route it uses. Any other address is refused by the code.
  • Caps. Each transaction has a hard USD ceiling. A bad day is a small day.
  • Dry-run by default. New logic ships in simulation mode first and only signs after a human reads the dry run.
  • Separate pool. The holder reward pot is handled by the stonk.fun contract on Solana and is not reachable by the agent.

Why build it

Most memecoins have a chart and a Telegram. The Pond wanted a product. ZFROG Mark 1 is proof that one frog, a public protocol and a few hundred lines of code can earn on Zama's stack without trusting anyone to hold the keys. It is also the easiest way to show what shielding, confidential vaults and staking actually look like when they run every day. Want to do it by hand? The five-step guide walks the same path.

Yields quoted on this page are read from the protocols at the time of each run. They change, and nothing here is a promise.
